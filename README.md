# Lumière — Premium Fine Dining Website

Built with:
- HTML5
- CSS3
- Vanilla JavaScript

## Run
Open `index.html` in a browser.

## Replace media
The site uses remote Unsplash images for the demo. Replace the image URLs in `index.html` and the feature background in `css/style.css` with your own local files when available.

For the hero video, place your file at:
`video/hero.mp4`

The `poster` currently points to:
`images/hero.jpg`

## Main JavaScript features
- Mobile navigation
- Sticky/scrolled navbar
- Smooth scrolling
- IntersectionObserver reveal animations
- Subtle parallax
- Gallery lightbox
- Keyboard controls
- Testimonial slider
- Reservation form validation
- Automatic footer year
